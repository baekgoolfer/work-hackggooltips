# Catch Everything 사용 안내

[English version: USER_GUIDE.md](USER_GUIDE.md)

이 문서는 개발자가 아닌 분이 Catch Everything을 처음 설치해서 쓰기 위한 안내예요. 앱 이름은 Catch Everything, 짧은 이름은 CATE이고 앱 파일은 `CATE.app`이에요. 설치 파일 `CATE-<버전>.dmg` 하나만 있으면 돼요. 이 앱을 만든 사람이 다른 이름을 골랐다면 파일과 앱에 그 이름이 쓰여 있고, 안내의 나머지는 그대로예요. 앱을 직접 빌드해서 다른 사람에게 나눠 주는 분을 위한 설명은 [DISTRIBUTE.md](DISTRIBUTE.md)에 있어요.

## 먼저 알아 두세요

- 이 앱은 회의에 나오는 **모든 사람의 목소리**와 **내 마이크**를 녹음해요. 내 마이크는 회의 앱에서 음소거해도 녹음돼요. 참가자에게 알리고 필요한 동의를 받는 것은 쓰는 분의 책임이에요 (9번).
- 지금까지 실제 통화에서 확인된 것은 **Zoom 통화뿐**이에요 (10번).
- 설치에는 인터넷, 약 4 GB 다운로드, 12 GB의 여유 저장 공간이 필요해요. 설치는 10분에서 40분쯤 걸려요.
- 이 앱은 빌드한 사람이 스스로 만든 인증서로 서명했고(자체 서명), Apple의 공증을 받지 않았어요. 처음 열 때 경고가 뜨는 것이 정상이에요 (3번). 같은 이유로 macOS는 이 파일을 누가 만들었는지 확인해 주지 못해요. 믿을 수 있는 곳에서 받은 파일만 여세요 (2번).

## 1. 필요한 것

- 애플 실리콘 Mac (M1 이상)과 macOS 14.4 이상. 화면 왼쪽 위 애플 로고 > 이 Mac에 관하여에서 확인해요. 인텔 Mac은 안 돼요.
- 인터넷 연결 (회사나 학교 네트워크의 VPN, 프록시, 방화벽이 pypi.org, huggingface.co, github.com을 막으면 설치가 멈춰요. 그때는 그 네트워크의 관리자에게 문의하세요).
- 회의록(회의가 끝난 뒤의 요약)까지 받으려면 Anthropic API 키와 Claude Code 도구가 필요해요. 없어도 녹음과 전사(말을 글로 바꾼 것)는 돼요.

## 2. 받기

`CATE-<버전>.dmg`는 이 파일을 만든 사람이 정한 곳(프로젝트의 릴리스 페이지나 클라우드 드라이브 링크 같은 파일 공유 서비스)에서 내려받아요. 믿을 수 있는 사람이나 곳에서 받은 파일인지 먼저 확인하세요. 이 앱은 마이크와 시스템 오디오를 녹음할 수 있어서, 누가 바꿔 놓은 파일이면 위험해요.

같이 있는 `.sha256` 파일(또는 받은 곳의 설명에 적힌 체크섬)로 파일이 그대로인지 확인할 수 있어요. 터미널에서 `shasum -a 256 CATE-<버전>.dmg`를 실행해 나온 숫자가 `.sha256` 파일의 숫자와 같으면 돼요. 이 확인은 파일이 전송 중에 깨지거나 바뀌지 않았다는 것만 알려 줘요. 체크섬을 알려 준 곳 자체를 믿을 수 있는지는 알려 주지 않아요.

## 3. 설치 (처음 한 번)

1. 내려받은 `.dmg`를 더블클릭해요. 창이 열려요.
2. 창 안의 **CATE** 아이콘을 **Applications** 폴더 아이콘으로 끌어다 놓아요. 창 안의 `README-install.txt`에도 같은 내용이 짧게 있어요.
3. Finder 왼쪽의 Applications를 열고, CATE를 **Control 키를 누른 채 클릭**(또는 마우스 오른쪽 클릭)해서 **열기**를 고르고, 나오는 창에서 한 번 더 **열기**를 눌러요. 경고는 "Apple이 확인하지 않은 앱"이라는 뜻이에요. 이 앱은 빌드한 사람이 스스로 만든 인증서로 서명(자체 서명)했고 Apple의 공증을 받지 않았어요.
4. 최근 macOS(15 이상)에서는 **열기** 버튼이 없을 수 있어요. 그럴 때는 창을 닫고, **시스템 설정 > 개인정보 보호 및 보안**으로 가서 아래로 내려 Catch Everything(또는 파일 이름인 CATE)에 대한 안내를 찾고 **그래도 열기**를 눌러요. 암호나 Touch ID를 물어봐요. 화면 문구는 macOS 버전마다 조금 달라요.
5. 앱이 열리면 화면 오른쪽 위 메뉴 막대에 아이콘이 생겨요. 노치나 메뉴 막대 정리 앱 때문에 가려질 수 있어요.

디스크 이미지 안에서 바로 열면 설치되지 않고 "먼저 Catch Everything 앱을 Applications 폴더로 옮겨 주세요"라는 안내가 떠요. 2번부터 다시 하세요.

## 4. 첫 실행: 구성 요소 설치

처음 열면 이런 창이 떠요: "Catch Everything 앱이 구성 요소를 설치해야 해요 (약 4 GB 다운로드, 인터넷 필요). 지금 시작할까요?" (Mac의 첫 언어가 한국어가 아니면 이 창은 영어로 떠요.) **시작**을 누르면 **터미널** 창이 열리고 7단계가 차례로 진행돼요. **나중에**를 누르면 메뉴 막대 아이콘에 "구성 요소: 설치 안 됨 - 설치 프로그램 실행" 항목이 남아 있고, 누르면 같은 창이 열려요. **설치가 끝나기 전에는 앱이 아무것도 녹음하지 않아요.** 메뉴의 첫 줄에 "설치가 끝날 때까지 자동 녹음이 꺼져 있어요"라고 나오고, 설치가 끝나면 몇 초 안에 저절로 사라져요. 설치 창은 한 번에 하나만 열려요. 이미 열려 있으면 "설치 프로그램이 이미 실행 중이에요"라고 알려 줘요.

| 단계 | 하는 일 | 내가 할 일 |
|---|---|---|
| 1 | 녹음 고지를 보여 주고, Mac이 조건에 맞는지(애플 실리콘, macOS 14.4 이상, 12 GB 여유, 인터넷) 확인해요 | 고지를 읽고 따르겠다면 **yes**를 입력해요 |
| 2 | 앱에 들어 있는 Python을 풀어요 | 없어요 |
| 3 | 프로그램 패키지와 음성 인식 모델(약 3.1 GB)을 내려받아요. 가장 오래 걸려요 | Mac을 켜 두고 인터넷에 연결해 두세요. 창을 닫으면 멈추고, 다시 실행하면 이어서 받아요 |
| 4 | 회의록용 Anthropic API 키를 물어봐요 (이미 저장돼 있으면 묻지 않아요. 키 값은 읽지 않고 항목이 있는지만 확인해요) | **1**: 지금 입력 (macOS 도구가 키를 물어보고, 입력은 화면에 보이지 않아요. 키는 설치 스크립트를 거치지 않아요). **2**: 나중에 앱의 설정에서 입력. 키 없이 넘어가면 녹음과 전사만 되고 회의록은 만들어지지 않아요 |
| 5 | 설정 파일을 만들어요. 이름은 Mac 사용자 이름의 첫 단어, 언어는 Mac의 언어를 따라요. 이미 있는 설정 파일은 건드리지 않아요 | 없어요 |
| 6 | 회의 저장 위치를 정해요. 기본은 내 Mac의 `~/Meetings`예요. Google Drive 계정이 하나만 연결돼 있으면 Drive에 저장할지 물어봐요 | Drive에 저장하면 오디오까지 Drive에 올라가요. 모르겠으면 그냥 Enter(기본값은 아니요)를 누르세요 |
| 7 | macOS 권한 요청이 나와요 (5번). 끝나면 요약이 나와요 | 허용을 눌러요 |

- 중간에 영어 줄이 나와도 설치가 멈추지 않으면 그냥 두세요. 특히 Python 3.12에 대한 안내가 나올 수 있어요.
- 멈추거나 오류가 나면 단계 번호, 원인, "이 스크립트를 다시 실행하세요"라는 안내가 나와요. 같은 방법(메뉴 항목 또는 알림 창의 시작)으로 다시 열면 끝난 단계는 건너뛰고 멈춘 곳부터 이어가요. 이미 있는 파일은 덮어쓰지 않아요.
- 설치가 끝나면 메뉴 막대 아이콘에서 **Quit**로 앱을 한 번 종료하고 다시 열어요. 그러면 새 설정을 읽어요.

## 5. macOS가 묻는 권한

| 권한 | 왜 필요한가요 | 안 주면 |
|---|---|---|
| 마이크 | 내 목소리를 녹음해요 (음소거해도 녹음돼요) | 내 목소리가 안 들어가요 |
| 시스템 오디오 녹음 | 상대방 목소리(내 Mac 스피커로 나오는 소리)를 녹음해요 | 상대방 소리가 비어 있어요 |
| 알림 | 녹음이 시작되고 끝날 때, 문제가 생길 때 알려 줘요 | 앱이 녹음해도 알 수가 없어요 |
| Google Drive 폴더 | Drive를 저장 위치로 골랐을 때만 | Drive에 저장이 안 돼요 |

Chrome 자동화 권한은 Google Meet 감지를 직접 켰을 때만 나와요 (기본은 꺼져 있어요). 실수로 거부했으면 **시스템 설정 > 개인정보 보호 및 보안**에서 Catch Everything을 찾아 켜세요.

## 6. 녹음과 회의록은 어디에 저장되나요

- 끝난 회의는 `~/Meetings/연-월/연-월-일_시분_제목/` 폴더에 저장돼요 (6단계에서 Drive를 골랐다면 Google Drive의 `My Drive/Meetings`). 안에 `transcript.md`(전사 원문), `meeting-note.md`(회의록), 오디오 `.m4a` 파일들이 있어요.
- 처리하는 동안에는 `~/Library/Application Support/MeetingCapture/sessions`에 임시로 있어요. 폴더 이름이 Catch Everything이 아니라 MeetingCapture인 것은 데이터 폴더, 로그 폴더, 키체인 항목이 이 내부 이름을 그대로 쓰기 때문이에요. 이미 Mac에 있는 것이 제자리에 남도록 한 거예요.
- 메뉴 막대 아이콘의 **Open Meeting Folder**로 가장 최근 회의 폴더를 열 수 있어요.
- **Google Drive를 저장 위치로 골랐다면 오디오가 든 폴더 전체가 Drive로 올라가고, 그 폴더에 접근할 수 있는 모든 사람이 볼 수 있어요.**

## 7. 일시정지, 중지, 종료

앱이 열려 있는 동안 통화를 감지하면 자동으로 녹음을 시작하고 알림을 보내요 (실제 통화에서 확인된 것은 Zoom뿐이에요). 감지하는 것은 Zoom, Microsoft Teams, 그리고 Slack 허들, Webex, Discord, FaceTime, 카카오톡, WhatsApp 같은 다른 통화 앱이에요. **개인 메신저의 통화도 포함돼요.** Google Meet는 기본으로 꺼져 있어요. 녹음하고 싶지 않은 앱은 메뉴의 **Call Apps**에서 앱별로 끄거나, 한 번 녹음된 앱은 **Never record <앱 이름>**으로 막을 수 있어요. 단, 4번의 설치를 끝내기 전에는 아무것도 녹음하지 않아요. 메뉴 막대 아이콘이 빨갛게 바뀌면 녹음 중이에요. 메뉴 이름은 영어 그대로 보여요.

| 메뉴 항목 | 하는 일 |
|---|---|
| Pause Auto Recording / Resume Auto Recording | 자동 녹음을 일시정지하고 다시 켜요 |
| Start Recording Now / Stop Recording Now | 직접 녹음을 시작하고 멈춰요 |
| Local-Only Meeting | 이 회의는 전사를 내 Mac 안에서만 하고 회의록(Claude)과 Drive 업로드를 하지 않아요 (이 회의만) |
| Pause Microphone | 설정으로 켜 둔 경우에만 보여요. 내 목소리를 일시적으로 녹음하지 않아요 |
| 설정… (Settings…) | 이름, 언어, Claude 키, 감지할 앱 등을 바꿔요 |
| Quit | 앱을 완전히 종료해요. 다시 열기 전에는 아무것도 녹음하지 않아요 |

앱을 열어 두어야 자동 녹음이 돼요. Mac을 켤 때 자동으로 열리게 하는 것은 이 설치에 들어 있지 않아요.

## 8. Mac 밖으로 나가는 것과 그 시점

| 무엇이 | 어디로 | 언제 |
|---|---|---|
| 프로그램 패키지와 음성 인식 모델 | 내려받기만 해요 (PyPI, Hugging Face, GitHub) | 설치할 때 한 번 |
| 음성 인식 | 나가지 않아요. 기본은 내 Mac 안에서 해요. 오디오는 Claude로 가지 않아요 | 항상 |
| 전사 텍스트, 회의 제목 힌트, 단어 목록 | Anthropic의 Claude (회의록을 만들 때) | Local-Only가 아닌 회의, API 키와 Claude Code가 있을 때 |
| 오디오가 든 회의 폴더 전체 | 저장 위치. Google Drive를 골랐다면 Drive와 접근 권한이 있는 모든 사람 | Local-Only가 아닌 모든 회의 |
| 캘린더 정보 | 기본은 나가지 않아요 (캘린더 조회는 꺼져 있어요) | 설정에서 직접 켰을 때만 |
| 외부 음성 인식 서비스 | 기본은 꺼져 있어요. 켜려면 터미널에서 동의 문장을 직접 입력해야 해요. 설정 창은 동의를 대신 해 주지 않아요 | 직접 켰을 때만 |

Local-Only Meeting을 켠 회의는 표의 셋째 줄부터 여섯째 줄까지(Claude, Drive 같은 저장 위치, 캘린더, 외부 음성 인식)가 모두 막혀요. 회의 제목과 대화 일부가 로그에 남을 수 있으니, 로그를 누구에게 보내기 전에 내용을 확인하세요.

## 9. 참가자에게 알리기

녹음하기 전에 참가자에게 알리고, 필요하면 동의를 받으세요. 나라, 소속 기관이나 회사의 규정, 회의의 성격에 따라 필요한 동의가 달라요. 잘 모르겠으면 법무나 정보보호를 아는 사람에게 먼저 확인하는 것이 안전해요. 예시 문구예요.

> 이 회의는 회의록을 만들기 위해 녹음됩니다. 말소리는 제 컴퓨터 안에서 글로 바뀌고, 그 글은 요약을 위해 Anthropic의 Claude로 전송될 수 있습니다. 녹음을 원하지 않으시면 지금 말씀해 주세요.

환자 정보, 고객 비밀처럼 규제를 받거나 기밀인 내용이 나오는 회의에는 계약과 소속 기관의 규정이 허용하지 않는 한 쓰지 마세요. 그런 회의에는 Local-Only Meeting을 켜도 오디오와 전사가 내 Mac에 남는다는 점을 기억하세요.

## 10. 지금까지 확인된 것과 확인되지 않은 것

- 확인된 것: **Zoom 통화**가 실제 통화에서 감지되고 녹음되는 것.
- 확인되지 않았어요: Microsoft Teams, Google Meet, Slack 허들, Webex, Discord, FaceTime, 카카오톡, WhatsApp 같은 다른 앱의 통화 감지. 되더라도 보장할 수 없어요. 감지가 되면 녹음이 시작되니, 녹음되면 곤란한 통화는 7번의 Call Apps에서 그 앱을 꺼 두세요.
- 확인되지 않았어요: 설정 창과 이 설치 알림 창은 화면으로 그려 보기만 했고 실제 사용 환경에서 써 본 적이 없어요. 화면이 어색하면 알려 주세요.
- 확인되지 않았어요: 이 설치 방식을 아무것도 깔려 있지 않은 새 Mac에서 처음부터 끝까지 해 본 것, 그리고 앱에 들어 있는 Python 3.12로 실제 전사를 돌려 본 것(패키지 설치와 불러오기는 만든 Mac에서 확인했어요). 막히면 터미널 화면의 마지막 몇 줄을 사진으로 찍어 보내 주세요.
- Apple의 공증을 받지 않은 앱이라 3번의 경고가 뜨는 것이 정상이에요. 공증 계획이나 일정은 없어요.

## 11. 문제가 생기면

| 증상 | 해 볼 것 |
|---|---|
| 앱이 "열 수 없다"고 해요 | 3번의 Control-클릭 > 열기, 안 되면 시스템 설정의 **그래도 열기** |
| 열 때마다 설치 창이 떠요 | 터미널 설치를 끝까지 진행하세요. 끝났는데도 뜨면 문의하세요 |
| "설치 프로그램이 이미 실행 중이에요"라고 해요 | 이미 열려 있는 터미널 설치 창에서 끝내세요. 안 보이면 설치 화면이 보이는 터미널 창을 모두 닫고 메뉴 항목으로 다시 시작하세요 |
| 설치가 끝났는데 녹음이 안 돼요 | 메뉴 첫 줄이 "설치가 끝날 때까지 자동 녹음이 꺼져 있어요"이면 설치가 아직 끝나지 않은 거예요. 터미널 설치 창이 "끝났어요"까지 갔는지 확인하세요 |
| 설치가 중간에 멈췄어요 | 화면의 단계 번호와 원인을 읽고, 인터넷과 저장 공간을 확인한 뒤 다시 시작하세요. 이어서 진행해요 |
| 알림이 안 와요 | 시스템 설정 > 알림에서 Catch Everything을 허용하세요 |
| 상대방 목소리가 비어 있어요 | 시스템 오디오 녹음 권한을 확인하세요 (5번) |
| 회의록이 안 만들어져요 | API 키를 넣었는지(설정 > Claude), Claude Code가 설치됐는지, Local-Only가 켜져 있지 않은지 확인하세요 |
| 그 밖의 모든 일 | **이 파일을 보내 준 분, 또는 이 파일을 받은 프로젝트 페이지에 문의하세요.** 메뉴의 **Open Logs**로 로그를 열 수 있지만, 회의 제목이 들어 있을 수 있으니 보내기 전에 확인하세요 |

## 12. 삭제하는 방법

1. 메뉴 막대 아이콘 > **Quit**로 앱을 종료해요.
2. Applications의 CATE를 휴지통으로 옮겨요.
3. `~/Library/Application Support/MeetingCapture` 폴더(내부 이름 그대로예요)를 지워요. 설정, Python 파일, 아직 저장 위치로 옮겨지지 않은 임시 녹음이 들어 있어요.
4. 키 입력을 했다면 키체인 접근 앱에서 "MeetingCapture Anthropic API key" 항목(역시 내부 이름이에요)을 지워요.
5. 음성 인식 모델을 지우려면 `~/.cache/huggingface/hub/models--mlx-community--whisper-large-v3-mlx` 폴더를 지워요 (약 3 GB).
6. 이미 저장된 회의 폴더(`~/Meetings` 또는 Drive)는 그대로 남아요. 필요 없으면 직접 지우세요.
